# Interface research

The review followed three desktop workflows in official product documentation. It covered selecting an instrument, creating space for the chart, and keeping price context visible.

| Workflow | What the products do | Pivluma decision |
| --- | --- | --- |
| Switch instruments | thinkorswim links watchlist selections to charts through a common link color. IBKR Desktop can synchronize symbols across tools in a custom layout. | A saved symbol uses the existing market-selection path. The active chart, forecast, and analyst use the same series. |
| Save a ticker | TradingView provides a quick action to save the current symbol. thinkorswim keeps watchlist management near the market tools. | Add and remove the current symbol from the Watchlist menu adjacent to the symbol picker. Store the list locally. |
| Make room for analysis | IBKR Desktop lets users hide chart-adjacent panels. thinkorswim lets users resize cells in its Flexible Grid. | Keep the resizable wide layout and compact tabs. Chart focus hides the analyst without rebuilding the chart or losing the current selection. |
| Read price context | TradingView exposes ticker and chart values in chart settings. IBKR watchlists commonly show last price and change. | The active series summary shows the last close and its signed percentage change from the previous observation. More significant digits keep low-priced instruments readable. |
| Maintain workspace context | TradingView saves chart layout properties. thinkorswim distinguishes shared watchlists from device-stored workspace preferences. | Save watchlist entries on this PC. Keep chart focus as an in-session choice and continue opening on BTC/USD. |
